<p>每天被问到的其实就是那几句，重复率很高：到底用哪种 IP、能不能按量、一号一环境具体交什么、出了问题谁管。与其一条条私聊解释，不如在这里一次写清楚。下面六个问题按被问的频率从高到低排，后面再补三段：计费方式的取舍、交付物清单、以及售后跟进的边界在哪儿。</p>

<h2>一、被问得最多的三个问题，一次答完</h2>
<h3>问题一：直接用机房 IP 行不行？</h3>
<p>行，但要知道差别在哪儿。机房段的 ASN 挂在云厂商名下，同段邻居密度高，长连接容易被上行争抢拖慢。低频、可重来的调用用机房段完全够；需要长期在线、多人同时操作、掉线代价高的场景，住宅出口更合适。</p>
<h3>问题二：动态和静态怎么挑？</h3>
<p>看账号需不需要「一直待在同一个地方」。需要就是静态，不需要且要按地区试探就是动态。混合也常见：核心号静态，试验号动态。别为了省钱把所有号都放动态池里轮换，会话漂移带来的问题比省下的钱贵。</p>
<h3>问题三：一号一环境到底交的是什么？</h3>
<p>交的是三样东西：一条独占的出口 IP、一份独立的登录凭证、以及一份配置记录（IP、ASN、城市、时区、开通时间）。不是交一台虚拟机，也不是交一个浏览器。环境要你自己在客户端里配，配置记录用来保证配得对、换人配得一样。</p>

<h2>二、按量和包月分别在什么时候划算</h2>
<h3>先算每天真实使用小时</h3>
<p>把一个号最近三十天的使用时长加起来除以三十。多数业务号的结果在两到三小时，只有二十四小时挂机的批处理才接近全天。按量在这个前提下通常更便宜，因为闲置的时间不产生费用。包月的价值在于成本可预期，不在于单价更低。</p>
<h3>一个能直接套的算法</h3>
<p>每天使用小时数乘三十，再乘小时单价，和包月单价对比。前者不到后者的七成，选按量；超过后者，选包月；落在中间看稳定性要求，要求高就包月。别忘了把起停的操作时间折算进去，频繁开关也是成本。</p>
<h3>淡旺季明显的团队怎么办</h3>
<p>有淡旺季的业务，别按峰值签年付。按量或可暂停的月付先跑，旺季前两周补容量，旺季结束停掉。这套做法比年付贵一成左右，但避免了半年闲置的钱，算下来通常更省。关键是提前规划补容量的时间，别等不够用了才临时找。</p>

<h2>三、一号一环境交付的到底是什么</h2>
<h3>四样东西，缺一样就不算交付</h3>
<p>出口 IP 及其归属信息、独立凭证、配置记录、以及换线或补线的通道。前两样是能立刻用的，后两样是出问题时能救命的。只有 IP 没有配置记录，换个人接手就得重新摸一遍；只有凭证没有换线通道，线路挂了只能干等。</p>
<h3>验收时动手做三件事</h3>
<p>第一，用 curl 打一次出口查询，确认 IP 和记录一致；第二，查 ASN 与 is_datacenter，确认是家宽且非数据中心；第三，连续请求二十次，看成功率和延迟分布。三件事做完大约十五分钟，比任何口头承诺都可靠。</p>

<h2>四、跑出问题之后，谁跟进、跟到哪一步</h2>
<h3>把「管到底」拆成三个节点</h3>
<p>第一个节点是响应：报障后多久有人回。第二个节点是定位：多久能给出是线路问题还是账号问题的结论。第三个节点是恢复：换线、补线或者协助排查，直到能正常跑通。三个节点都该有明确时限，口头说「尽快」等于没承诺。</p>
<h3>报障时给什么，决定了处理速度</h3>
<p>时间点、出口 IP、请求方式、返回码、复现步骤，五样凑齐，定位基本一轮就够。只说「用不了」，来回问三轮是常态。这不是对方不专业，是信息不够。</p>
<h3>走哪个通道报，也有讲究</h3>
<p>能开工单就别只在聊天群里问一句。工单有编号、有记录、有跟进状态，三个月后还能翻出来；群里的消息半天就被刷过去了。同一类问题连着报三次，就该整理成一条固定模板，下次直接套用，省下的时间比省下的钱实在。</p>
<h3>哪些不在跟进范围内</h3>
<p>账号自身的历史状态、平台侧的规则判定、你自己客户端的代码缺陷，这三类供应商管不了，也不该指望。把边界说清楚，合作反而更顺。真正该被追责的是线路不通、归属不对、频繁掉线这类出口侧的问题。</p>

<h2>常见问答</h2>
<h3>下单后多久能用上？</h3>
<p>答：常见是当天，部分需要人工开通的会到下一个工作日。签之前把开通时限写清楚，别只听「很快」。</p>
<h3>用着不合适能换吗？</h3>
<p>答：多数供应商支持在开通初期换线，具体次数和时限看条款。建议把「首次开通七天内可换」写进约定。</p>
<h3>按量计费的流量怎么算？</h3>
<p>答：通常按出口侧的上行加下行总量计。长连接空转、失败重试都会计入，做预算时留两成余量。</p>
<h3>多个号能共用一份凭证吗？</h3>
<p>答：技术上可能可以，但不建议。共用凭证等于共用出口，一号一环境的意义就没了。</p>
